# PediDent 부스 장부 (3인 공유)

2026 부산대 치의학전문대학원 종합학술대회 현장 판매용입니다.
세 사람이 각자 폰으로 입력해도 몇 초 안에 하나의 장부로 합쳐집니다.

## 들어 있는 것

```
pedident/
├─ netlify.toml            배포 설정
├─ package.json            함수가 쓰는 라이브러리
├─ public/index.html       실제 화면 (앱 전체)
└─ netlify/functions/api.js  장부를 읽고 쓰는 서버 함수
```

기록은 Netlify Blobs에 저장됩니다. 별도 데이터베이스나 다른 서비스 가입은 필요 없습니다.

## 배포 순서

1. 이 폴더를 통째로 GitHub 저장소에 올립니다.
2. Netlify에서 **Add new project → Import an existing project**로 그 저장소를 고릅니다.
3. 빌드 설정은 `netlify.toml`에 이미 들어 있으니 그대로 두고 Deploy를 누릅니다.
4. 배포가 끝나면 **Project configuration → Environment variables**에서 아래를 추가합니다.

   | Key | Value |
   |---|---|
   | `BOOTH_PIN` | 원하는 접속 코드 (예: `2026bexco`) |

5. 환경 변수를 넣은 뒤 **Deploys → Trigger deploy → Deploy site**로 한 번 더 배포합니다.
   (환경 변수는 재배포해야 함수에 반영됩니다.)

GitHub 없이 하려면 Netlify CLI로 `netlify deploy --prod`를 써도 됩니다.
UI 드래그 앤 드롭은 함수 의존성 설치가 빠질 수 있어 권하지 않습니다.

## 세 사람 세팅

1. 주소를 세 명에게 보냅니다.
2. 각자 접속 코드를 한 번 입력하면 그 폰에 저장됩니다.
3. 홈 화면에 추가해 두면 앱처럼 열립니다.
   - 아이폰: 사파리 공유 버튼 → 홈 화면에 추가
   - 안드로이드: 크롬 메뉴 → 홈 화면에 추가

## 행사 전에 할 일

- 설정 탭에서 품목·가격·준비 수량을 실제와 맞춥니다. 한 사람이 정리하면 세 기기에 같이 반영됩니다.
- 담당자 칸에 세 명 이름을 넣으면 결제 등록에서 버튼으로 고를 수 있습니다.
- 연습으로 몇 건 넣어 보고, 설정 탭의 판매 내역 전체 삭제로 비운 뒤 시작합니다.

## 알아 둘 것

- **인터넷이 끊겨도 입력은 됩니다.** 화면 오른쪽 위에 오프라인과 대기 건수가 뜨고, 연결되면 자동으로 올라갑니다. 벡스코 와이파이가 불안하면 LTE를 켜 두세요.
- **주소를 아는 사람은 누구나 들어올 수 있습니다.** 접속 코드가 유일한 잠금이고, 고객 이름·연락처·주소가 그 안에 있습니다. 코드는 부스 인원끼리만 공유하고 행사 후에는 Netlify에서 사이트를 지우거나 비공개로 돌리세요.
- 같은 판매건을 두 사람이 동시에 고치면 나중에 저장한 쪽이 남습니다. 배송 정보는 한 사람이 맡는 편이 안전합니다.
- 정산이 끝나면 정산 탭에서 CSV를, 설정 탭에서 백업 파일을 받아 두세요.
